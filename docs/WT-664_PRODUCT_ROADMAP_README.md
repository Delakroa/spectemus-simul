# WT-664 — Продуктовая дорожная карта в README

## Проблема

Корневой README честно говорил, что текущая preview работает только в одной
домашней сети. Но он не объяснял, что просмотр из разных городов — главная
личная цель продукта и уже спроектированное следующее направление. Такой текст
выглядел как окончательное ограничение, а не как понятная граница текущей
версии.

Также пользователю было видно, что часть видеоформатов пока не гарантирована,
но не было видно курса на их расширение.

## Решение

README теперь отделяет текущее поведение от направления продукта:

- LAN preview остаётся честно обозначенной как доступный сейчас режим;
- явно названа цель: приватный совместный просмотр своего фильма из разных
  городов;
- показаны шаги от LAN до закрытой Internet alpha и стабильного Internet
  release без выдуманной календарной даты;
- названы обязательные gates: HTTPS/TURN, безопасные account/invite,
  тестирование двух реальных сетей, UDP fallback, reconnect и измерение
  стоимости;
- описан путь к более широким форматам: проверка на устройстве сейчас, затем
  local normalizer с временной копией на компьютере host-а и без upload
  исходного фильма.

## Что не обещает дорожная карта

- Internet mode ещё не реализован и не даёт текущему LAN invite права работать
  через интернет.
- Не обещается поддержка любого контейнера, HEVC/DTS или повреждённого файла
  до реальной проверки и normalizer evidence.
- В план не входят торрент-функции, каталог фильмов, upload оригиналов,
  запись или обход DRM.
- Дата внешнего релиза не называется до прохождения security, network,
  reliability и cost gates из [WT-652](WT-652_INTERNET_MODE_ARCHITECTURE.md).

## Проверка

```bash
pnpm format:check
git diff --check
```

Ручная проверка: человек, открывший README, понимает одновременно, что можно
проверить сегодня и какой безопасный путь ведёт к просмотру с близким человеком
из другого города.
