# SPS-693 — готовность к физическому прогону Mac ↔ Windows

## Цель

Убрать дефекты, из-за которых прогон фазы 0 либо не исполним, либо не даёт
интерпретируемого результата. Аудит показал: половина матрицы (MKV/нормализатор)
могла не запуститься вовсе, а требование «любой дефект → отдельный LAN-тикет»
было невыполнимо, потому что сайдкары не оставляли ни строки логов.

## Изменения

### Подпись macOS preview-сборки

`.github/workflows/desktop-installer.yml` — preview собирается с ad-hoc подписью
(`-c.mac.identity=-` вместо `null`). Без неё вложенные Mach-O (`livekit-server`,
`ffmpeg`, `ffprobe`) остаются неподписанными: приложение стартует «зелёным», а
media-половина прогона умирает на чистом Mac.

### Нормализуемые ошибки диагностики

`frontend/src/features/rooms/use-room-session.ts` — в
`isNormalizableDiagnosticFailure` добавлен `NO_VIDEO_TRACK`. Браузер демуксит
контейнер, но не находит декодируемое видео (MKV HEVC без платформенного
декодера на Windows) — такой файл теперь уходит в локальную подготовку копии, а
не отклоняется с сообщением, обвиняющим сам файл. Файлы действительно без
видеодорожки по-прежнему отсеивает ffprobe внутри нормализатора.

### Логи сайдкаров

`desktop/src/main/sidecars.mjs`, `desktop/src/main/main.mjs` — backend и LiveKit
больше не спавнятся с `stdio: "ignore"`. Их вывод пишется в
`<userData>/logs/backend.log` и `<userData>/logs/livekit.log` (дозапись, файл
усекается при превышении 8 МБ). Каталог логов передаётся в `start()` параметром
`logDirectory`; при его отсутствии используется `<runtimeDirectory>/logs`.
Дескрипторы закрываются после остановки детей. Если каталог недоступен, запуск не
прерывается — сайдкар просто стартует без лога.

### Причина недоступности нормализатора

`desktop/src/main/sidecars.mjs`, `main.mjs`, `media-library.mjs` — добавлена
`probeMediaTools`, возвращающая причину отказа (код ошибки spawn, сигнал, статус,
первая строка stderr) вместо голого `false`. Интерфейс теперь различает «сборка
без ffmpeg» и «ffmpeg на месте, но не стартует» — это разные дефекты и разные
тикеты. `hasMediaTools` сохранена как тонкая обёртка.

### Перетаскивание файла в desktop-сборке

`frontend/src/pages/HomePage.tsx` — при наличии `spectemusDesktop.pickMediaFile`
drop отклоняется с подсказкой выбрать файл кнопкой. У файла из drop нет пути на
диске, поэтому он уходил в браузерный путь мимо подготовки копии: пункт матрицы
можно было «пройти», ни разу не запустив тестируемую функцию.

### Запуск сайдкаров в CI

`scripts/desktop-installed-app-smoke.mjs` — smoke установленного приложения не
только проверяет наличие файлов, но и запускает `ffmpeg -version`,
`ffprobe -version` и `livekit-server --version` из установленного бандла.
Присутствие файла ничего не доказывает: карантинный или неподписанный бинарник
лежит на месте и убивается системой при запуске.

## Проверка

```bash
node --test desktop/src/main/*.test.mjs
node --test scripts/*.test.mjs
```

Локально в этой задаче проверено: desktop 45/45, scripts 37/37, frontend 145/145,
`tsc -b` и `eslint --max-warnings 0` чисты. Новый тест
`install smoke ловит присутствующий, но незапускающийся media sidecar` проверяет
именно поведение, ради которого добавлен запуск бинарников.

## Не входит в задачу

Пункты категории B из аудита (фиксированный битрейт без проверки свободного
места, свип temp-каталога при рестарте рантайма, потеря кнопки reconnect вместе с
закрытым баннером, write-only канал отзывов) остаются открытыми: с ними прогон
всё ещё даёт валидные свидетельства при соблюдении подготовки из раздела ниже.

## Что оператор обязан знать до прогона

- **Windows, брандмауэр.** Сеть должна быть в профиле «Частная» (в Public попап
  Defender не появится вовсе), `scripts/windows-lan-firewall.ps1` выполнить
  вручную с повышением прав. Иначе блокировка неотличима от падения LiveKit.
- **macOS, карантин.** `xattr -cr "/Applications/Spectemus Simul.app"` —
  обязательный шаг установки preview, а не примечание.
- **VPN выключить на обеих машинах**: фильтр виртуальных интерфейсов ненадёжен на
  Windows, а пикер обещает, что VPN отфильтрованы.
- **Файлы выбирать только кнопкой «Выбрать файл»** — перетаскивание в
  desktop-сборке теперь отклоняется намеренно.
- **Проверка удаления временной копии.** Путь: macOS
  `$TMPDIR/spectemus-simul/normalized-media`, Windows
  `%TEMP%\spectemus-simul\normalized-media`. Каталог очищается при старте, поэтому
  порядок такой: зафиксировать файл и размер во время сессии → завершить сессию
  штатно (не force quit) → проверить каталог до повторного запуска.
- **Место на диске:** ~2.8 ГБ на час подготовленной копии независимо от размера
  источника; для трёх MKV-строк держать ≥20 ГБ свободного.
- **Не закрывать баннер ошибки LiveKit** — вместе с ним исчезает единственная
  кнопка переподключения. Reconnect воспроизводить отключением сети, а не
  убийством приложения.
