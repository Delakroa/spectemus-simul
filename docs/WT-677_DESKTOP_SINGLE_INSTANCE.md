# WT-677 — защита от второго запуска desktop host

## Цель

Не допустить, чтобы пользователь случайно открыл две копии Spectemus Simul на
одном компьютере. Раньше вторая копия могла дойти до проверки портов и показать
ошибку про занятый backend или LiveKit, хотя первая копия приложения работала
нормально.

## Реализовано

- Electron получает системную блокировку единственного экземпляра до инициации
  desktop host.
- Если приложение уже работает, вторая копия сразу завершается и не запускает
  backend, LiveKit или gateway.
- Первый экземпляр получает событие повторного запуска, разворачивает окно при
  необходимости и переводит его на передний план.

## Граница защиты

Это защищает от обычного повторного открытия приложения. После жёсткого
завершения процесса или выключения компьютера система не должна автоматически
убивать процессы только по номеру PID: он может уже принадлежать другой
программе. Для такого случая остаётся безопасный port preflight с понятным
сообщением. Отдельный будущий механизм сможет чистить только подтверждённые
осиротевшие процессы Spectemus Simul по их проверяемому владению.

## Проверка

```bash
pnpm --dir desktop test
pnpm check
```

Ручная проверка: запустить приложение, затем открыть его второй раз. Должно
остаться одно окно и один набор локальных сервисов; существующее окно становится
активным.
