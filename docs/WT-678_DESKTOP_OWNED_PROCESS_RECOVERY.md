# WT-678 — безопасное восстановление процессов desktop host

## Цель

После аварийного закрытия приложения backend или LiveKit могли остаться в памяти
и занять порты следующего запуска. Пользователю приходилось вручную искать и
останавливать процессы.

## Реализовано

- Desktop host сохраняет защищённый локальный журнал только своих sidecar-процессов.
- Перед проверкой портов следующий запуск читает этот журнал и сверяет PID с
  командой запущенного процесса.
- Завершается только процесс, одновременно совпадающий по PID и признакам
  команды запуска Spectemus backend или LiveKit.
- Если PID уже принадлежит другой программе или команда не совпала, процесс не
  затрагивается. Обычная проверка порта покажет понятную ошибку.
- После чистого завершения приложения журнал удаляется.

## Проверка

```bash
pnpm --dir desktop test
pnpm check
```

Ручной сценарий: аварийно завершить работающий desktop host, затем запустить
приложение ещё раз. Новый запуск должен восстановить только свои старые sidecars
и открыть host без ручной очистки портов.
