# WT-691 — явная проверка токена приглашения

## Цель

Не передавать в сервис пустое или отсутствующее значение токена при входе по
приглашению в Internet room.

## Изменение

- `inviteToken` теперь помечен `@NotBlank` вместе с уже существующей проверкой
  формата из 43 URL-safe символов.
- Запрос без `inviteToken` завершается `422 VALIDATION_FAILED` на HTTP-границе;
  сервис и хранилище не вызываются.

## Проверка

`PublicAccessControllerTest` проверяет ответ для `{}` и отсутствие вызова
`PublicAccessService`.

## Граница задачи

Это уточнение валидации, а не изменение модели доступа. Одноразовость
приглашений, HMAC-фингерпринты и проверка прав владельца остаются прежними.
