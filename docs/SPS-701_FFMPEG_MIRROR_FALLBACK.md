# SPS-701 — fallback-зеркала исходного архива FFmpeg

## Причина

Installer-run `31251483143` подтвердил исправление SPS-700: Apple Silicon
успешно импортировал закреплённый ключ FFmpeg и начал настоящую сборку. Однако
Windows остановился раньше, при получении исходного архива с
`ffmpeg.org/releases`: соединение несколько раз завершалось ошибками `curl 28`
и `curl 35`. Повтор одной и той же ссылки семь раз занимает несколько минут и
не помогает, если недоступен именно сервер или маршрут до него.

## Изменения

`scripts/build-media-sidecar.sh` теперь чередует источники для одного и того же
архива `ffmpeg-8.1.2.tar.xz`:

1. официальный `ffmpeg.org/releases`;
2. зеркало VideoLAN;
3. зеркало Aliyun Slackware.

Подпись сначала берётся с официального release-сервера, а при его
недоступности — с Aliyun. VideoLAN используется только для архива: рядом с ним
нет подписи.

Каждая копия архива всё равно проходит прежнюю обязательную проверку GPG
закреплённым ключом с fingerprint
`FCF986EA15E6E293A5644F10B4322F04D67658D8`. Зеркало не может сделать чужой
архив доверенным и не меняет лицензионные или исходные требования FFmpeg.

## Проверка

Regression-тест подставляет `curl`: официальный URL отвечает временной
ошибкой, следующий запрос уходит на зеркало и только тогда публикует полный
файл. Отдельно проверяется отказ вызова без URL.

```bash
node --test scripts/build-media-sidecar.test.mjs
bash -n scripts/build-media-sidecar.sh
pnpm format:installer
git diff --check
```

После merge требуется новый полный `Desktop installer` для Apple Silicon,
Intel Mac и Windows. Только три успешные сборки открывают физический
Mac ↔ Windows прогон фазы 0.
