# SPS-703 — не терять управление переподключением LiveKit

## Цель

После обрыва LiveKit у пользователя должен оставаться способ вернуть видео. Сейчас
кнопка «Повторить LiveKit» существует только внутри баннера ошибки, и её можно
потерять безвозвратно — а LiveKit SDK не создаёт событие повторно, потому что
`disconnected` для неё терминальный.

Это прямо мешает предстоящему физическому прогону: сценарий обязательно включает
reconnect, и оператор записал бы «reconnect не работает», хотя причина в другом.

## Что было

Потерять кнопку можно двумя путями.

1. **Закрыть баннер.** «Скрыть ошибку» вызывает `clearUserError`, который снимает
   `userError` безусловно. Запасной блок с `liveKitError` кнопки не имел, а
   `retryLiveKitConnection` была достижима только через действие баннера.
2. **Дождаться ошибки другой области.** Свежая websocket-ошибка перезаписывала
   ещё не решённую LiveKit-ошибку. Дальше «Переподключить» снимал её по
   совпадению `area` — и вместе с ней исчезала LiveKit-ошибка, которую никто уже
   не восстановит.

Итог одинаковый: чат работает, видео нет, кнопки нет нигде. Помогает только выход
из комнаты или перезагрузка страницы.

## Изменения

- `frontend/src/pages/HomePage.tsx` — запасной блок `liveKitError` получил кнопку
  «Повторить LiveKit», вызывающую то же действие, что и баннер.
- `frontend/src/features/rooms/use-room-session.ts` — добавлен
  `keepUnresolvedUserError`: свежая ошибка не вытесняет ещё не решённую ошибку
  другой области. Применён в двух местах, где websocket-ошибка могла лечь поверх
  LiveKit-ошибки — исчерпание попыток переподключения и битое событие комнаты.

## Проверка

```bash
frontend/node_modules/.bin/vitest run --root frontend
```

Локально: 146 тестов зелёные, `tsc -b` и `eslint --max-warnings 0` чисты.

Новый тест «ошибка websocket не затирает неисправленную ошибку LiveKit» проверен
откатом: без `keepUnresolvedUserError` он падает, с ним проходит.

## Граница задачи

Автоматическое переподключение LiveKit не добавлялось — оно осталось ручным, как и
было задумано. Задача возвращает лишь доступность ручного действия.
