# SPS-692 — не включать заново выключенный звук локального preview

## Цель

Сохранять выбор host: если звук локального preview выключен, повторная привязка
видеоэлемента не должна включать его обратно.

## Изменение

- `attachHostPreview` больше не выставляет `videoElement.muted = false`.
- Состоянием звука владеет playback sound control интерфейса
  (`playbackMuted` / `playbackVolume` → `isPlaybackSoundMuted`). React пишет проп
  `muted` только при изменении значения, поэтому императивная перезапись при
  каждой привязке «прилипала»: элемент звучал, а интерфейс показывал выключенный
  звук.
- Привязка повторяется при republish и восстановлении показа, поэтому баг
  проявлялся именно после действия «Восстановить».

## Проверка

`use-room-session-host-controls.test.tsx` доводит публикацию до `live`, выключает
звук и повторно привязывает preview через `setHostPreviewElement`: элемент
остаётся выключенным. Тест проверен возвратом прежней строки — без исправления он
падает.

## Граница задачи

Это исправление рассинхрона управления звуком, а не изменение публикации.
`autoplay` и `playsInline` по-прежнему выставляются при привязке: они дублируют
значения из разметки и не конфликтуют с состоянием интерфейса.
