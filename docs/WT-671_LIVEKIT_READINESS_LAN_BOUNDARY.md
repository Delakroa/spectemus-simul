# WT-671 — readiness LiveKit и граница LAN preview

## Readiness LiveKit

Desktop host больше не определяет готовность LiveKit через `GET /`. У LiveKit
Server нет закреплённого отдельного HTTP health endpoint для этого назначения,
а ответ корня зависит от версии и конфигурации. Вместо этого supervisor ждёт
TCP-подключения к локальному signal-порту `7880`: именно его затем используют
клиенты для подключения к комнате.

Проверка покрыта тестом с настоящим локальным TCP server. Это не подменяет
сессию гостя: media, audio и join по-прежнему подтверждаются физическим
Mac ↔ Windows smoke.

## Граница сети

LAN gateway намеренно слушает адрес host-а, чтобы гости в одной сети могли
открыть invitation. Share sheet теперь явно предупреждает: ссылка предназначена
только для близких людей в доверенной домашней сети, а не для public Wi-Fi или
незнакомой сети.
