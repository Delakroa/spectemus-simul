# SPS-702 — закреплённая detached-подпись архива FFmpeg

## Причина

SPS-701 сделал получение исходного архива устойчивее: после временной ошибки
официального release-сервера сборщик переходит на зеркало. Detached-подпись
`ffmpeg-8.1.2.tar.xz.asc` всё ещё загружалась по сети, поэтому одновременная
недоступность двух серверов подписи останавливала сборку даже при доступном
архиве на VideoLAN.

## Изменения

В репозиторий добавлена точная detached-подпись
`scripts/ffmpeg-8.1.2.tar.xz.asc`. Она независимо получена с официального
FFmpeg release-сервера и зеркала Aliyun; обе копии совпали по SHA-256:

```text
0a0963fccd70597838073f3e31b20f4a4d8cc2b5e577472c9a5a1f22624246f8
```

Сборщик больше не загружает подпись. Он получает из сети только архив, затем
проверяет его локальной подписью через GPG-ключ FFmpeg, уже закреплённый в
репозитории. Повреждение подписи не даст опубликовать sidecar: GPG остановит
сборку до распаковки архива.

## Граница доверия

Это не заменяет и не отключает криптографическую проверку. Репозиторий хранит
публичный ключ и detached-подпись конкретной версии FFmpeg; доверенным архив
становится только после успешного `gpg --verify`. При смене `FFMPEG_VERSION`
нужно обновить архивную подпись вместе с версией и заново подтвердить её
fingerprint и проверку GPG.

## Проверка

- unit-тест проверяет CRC-24 ASCII-armour закреплённой подписи;
- подставной `curl` завершится ошибкой, если сборщик попробует загрузить ключ
  или любую `.tar.xz.asc` подпись;
- настоящий installer-run на macOS и Windows выполняет `gpg --verify` перед
  распаковкой.

```bash
node --test scripts/build-media-sidecar.test.mjs
bash -n scripts/build-media-sidecar.sh
pnpm format:installer
git diff --check
```
