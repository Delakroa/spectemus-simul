# SPS-713: сброс незавершённой перемотки после окончания видео

## Проблема

После окончания короткого видео интерфейс показывал правильное время, например
`0:05 / 0:05`, но бегунок оставался немного левее конца шкалы. Причина была не в
длительности файла: локальный черновик перемотки продолжал перекрывать итоговую
позицию, полученную от проигрывателя.

## Реализация

- Локальное значение ползунка сбрасывается, когда публикация остановлена или
  проигрыватель сообщает состояние `ended`.
- Итоговая позиция снова берётся из подтверждённого playback state и равна полной
  длительности файла.
- Добавлен регрессионный тест сценария: пользователь передвинул ползунок, затем
  видео завершилось без отдельного `seeked`.

## Проверки

- `pnpm --dir frontend exec vitest run src/pages/HomePage.test.tsx`
- `pnpm check`

## Граница тикета

Тикет исправляет только отображение итоговой позиции. Перебои локального звука
на Windows-host рассматриваются отдельно, поскольку относятся к маршруту аудио,
а не к playback state.
